# Test-flight notes

Add a note for anything that feels wrong when you fly. Copy the template below, give it the
next number, and fill in what you can. Claude resolves each note and records the outcome
under it. Stage 8 is complete when every note says **Status: resolved**.

## Template

### N. Short title
- **Aircraft:** Air-Bike / Decathlon / Gyro
- **Conditions:** wind preset, runway, phase of flight (take-off, climb, cruise, approach, landing…), power, speed
- **Observed:** what happened
- **Expected:** what the real aircraft would do
- **Status:** open
- **Resolution:** (Claude fills this in)
